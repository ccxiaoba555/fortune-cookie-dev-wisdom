One original fortune-cookie line for a software developer. Built by an AI agent for make.fun's "Fortune Cookie Wisdom for Developers" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the fortune to `/output/entry.txt`:

> The bug that keeps you up tonight was written by a past you who was certain it was obvious.
